Romeo & Juliet: A Dark-Humor Love Story

A creative website inspired by William Shakespeare's Romeo and Juliet, presenting the classic tragedy through a sarcastic, darkly humorous interpretation of romance, family conflict, and catastrophic communication failures.

Created as part of a second-year BSIT web development activity.

Features

Story Timeline

Presents major events from the story, including:

- The lovers' first encounter.
- The balcony scene.
- Their secret marriage.
- The duel and its consequences.
- The undelivered letter.
- The tragic ending.

The Verona Peace & Regret Memorial

A fictional memorial event that humorously explores the consequences of the tragedy.

- Event information and fictional venue details.
- Countdown to the fictional memorial.
- A dedicated section linking visitors to the RSVP form.

Evidence Gallery

A themed collection of story-inspired exhibits, including:

- The Rose-Tinted Red Flags.
- The Balcony Incident.
- The Undelivered Letter.
- The Family Meeting.

Interactive Features

- Mobile navigation menu.
- Page-loading transition.
- Scroll-triggered reveal animations.
- Live countdown timer.
- RSVP form with validation and response feedback.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Navigate through the story, gallery, fictional memorial, and RSVP sections.

Project Files

- "index.html" — Website content and structure.
- "style.css" — Visual design, layout, and responsive styling.
- "script.js" — Navigation behavior, countdown, animations, and RSVP interactions.

Important Note

This is a fictional school project website. The memorial event and RSVP are demonstrations only. Form responses are displayed in the browser and are not submitted to a server or saved as registrations.
